# 并发分组

组内按命名线路**并发**执行，按全部完成或任意完成汇合后，再经 Success / Failure 出组。

## 用途

- 并行调用多个下游（如多路 HTTP、多路校验）
- 需要统一汇合结果（`msg` 变为含 `branches` 的 JSON）

## 组框锚点

| 锚点 | 说明 |
| ---- | ---- |
| 左入 | 外部进入本分组 |
| 公共并发入 | 扇出：拉出边并选择线路名，接到各线路首节点 |
| 成功汇聚 | 组内成功路径连回此处 |
| 失败汇聚 | 组内失败路径连回此处 |
| 右出 | 汇合后出组（视觉单端点，边标签 Success / Failure） |

## 配置要点

| 字段 | 说明 |
| ---- | ---- |
| branches | 线路名列表 |
| completeMode | `all` 全部完成 / `any` 任意完成 |
| cancelOthersOnAny | 任意完成时是否协作取消其余线路 |
| timeoutSec | 超时秒数；0 表示不超时 |

## 下游消息

汇合后消息体形如：

```json
{
  "branches": {
    "branch1": { "ok": true, "msg": ... },
    "branch2": { "ok": false, "error": "..." }
  }
}
```
