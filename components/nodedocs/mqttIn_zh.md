# MQTT 收

订阅 Broker 主题；消息到达后触发流程（入口节点）。

## 用途

- 作为流程起点，**无入边**，仅有 Success 出边
- 载荷写入 msg.Data；metadata 含 mqttTopic、mqttQos、mqttRetained

## 连接并响应

| 状态 | 行为 |
| --- | --- |
| 开关开启 + 草稿 | 保存后自动连接并订阅，消息走草稿流程 |
| 流程已发布 | **始终**自动连接（与开关无关） |
| 开关关闭 + 草稿 | 不连接 |

浮动栏「测试连接」：用当前属性短暂连接并订阅，成功或失败后立即断开并提示结果。

## 配置要点

| 字段 | 说明 |
| --- | --- |
| connectAndRespond | 编辑态是否自动连接 |
| server | Broker 地址 |
| topic / qos | 订阅主题与 QoS |

## 连线

从右侧 Success 出口连到下游；不可接收入边。
